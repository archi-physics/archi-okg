# archi-okg has moved to archi-physics/archi

**This repository is archived and read-only.** Archi v3 (the HEP
distribution of OKG) is now developed in
[archi-physics/archi](https://github.com/archi-physics/archi), on the
[`archi_v3`](https://github.com/archi-physics/archi/tree/archi_v3) branch.

- **Code:** clone `archi-physics/archi` and check out `archi_v3`. That
  branch started from this repository's final commit, `011f5d64`, with its
  history kept, so every commit here is also there.
- **Pull requests:** open them against `archi_v3` in archi-physics/archi.
  This repository takes no new commits.
- **Open PRs and issues** from here were moved to archi-physics/archi or
  closed with a link to their successor.
- **Why:** [ADR 0002](https://github.com/archi-physics/archi/blob/archi_v3/docs/adr/0002-archi-3.0-release.md),
  decision D1, makes archi-physics/archi the home of the v3 line. The
  work is tracked as PACT `r3-release-home`.

`main` in archi-physics/archi is still the v2 application until the 3.0
cutover, when `archi_v3` becomes `main`. If a link above to `archi_v3`
stops working after that, use `main`.
